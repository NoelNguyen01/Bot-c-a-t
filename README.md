# 🐱 Neko Discord Bot (JavaScript / Node.js — discord.js v14)

Bot Discord đa tính năng được viết bằng **JavaScript (Node.js)** sử dụng thư viện **discord.js v14** mới nhất:
- 🪙 **Kinh Tế & Ngân Hàng:** Gửi / Rút tiền, Vay vốn ngân hàng (tối đa 100M, lãi theo phút, trả góp giảm lãi), Lao động công ích chuộc nợ, Chuyển tiền (phí 20%), Daily, Work, Beg, Rob, Top Đại Gia, Top Nợ.
- 🎰 **Sòng Bạc (Casino):** Tài Xỉu (Bão ăn sạch), Xì Dách Blackjack (Đếm ngược 30s, chống thoát ván, trừ cược ngay, Xì Bàng/Xì Dách/Ngũ Linh), Tung đồng xu Coinflip, Quay hũ Slots (Jackpot x10), Bầu Cua Tôm Cá, Top Thần Bài.
- 🧧 **PvP & Lì Xì:** Kéo búa bao solo 1v1 nút bấm, Ném bao lì xì server giật thưởng ngẫu nhiên.
- 👑 **Admin:** Buff money, Set/Add/Trừ tiền, Chỉnh tỉ lệ thắng sòng bạc (cheat).

---

## 🚀 Hướng Dẫn Cài Đặt & Khởi Chạy

### 1. Cài đặt thư viện:
```bash
npm install
```

### 2. Cấu hình Token:
Tạo file `.env` (hoặc đổi tên từ `.env.example`) và dán Bot Token của bạn:
```env
DISCORD_TOKEN=your_bot_token_here
```

### 3. Chạy Bot:
```bash
npm start
# Hoặc:
node index.js
```

*Hỗ trợ cả tiền tố `!` (hoặc `n!`) và **Slash Commands** (`/`) hiện đại.*
